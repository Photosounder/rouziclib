# WAHE Thread Backend

Define `RL_WAHE_THREADS` and `WAHE_THREADING_UTILS` before including rouziclib and
wahe_utils.h in a shared-memory Wasm WAHE module. Supply the usual WAHE imports,
allocator, TLS exports, and threading utility implementation.

This backend exports `module_thread_entry` and dispatches messages generated by
`rl_thread_create` to module-local function pointers. Do not define another thread
entry export in the same module. Each worker receives a dynamically allocated
256 kB stack and independent TLS from the host. Joins release its runner and stack.

Mutexes preserve the native recursive-acquisition behavior. Semaphores and atomic
operations use shared Wasm memory; waits sleep rather than spin. Native thread
priorities are not exposed to Wasm. Direct detached thread creation is unsupported:
retain and join each handle, or use an application-owned detached-worker registry
that creates joinable workers and reaps them before shutdown.

Define `RL_WAHE_FILE_PREFS` to enable the existing file-backed preferences helpers
in a WAHE module that also supplies the required host-mediated filesystem helpers.
